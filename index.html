我該去哪裡

找出彼此距離相近的地點，讓你不必跑太遠就能到下一站。

金鑰只會儲存在這個瀏覽器（localStorage）。需要啟用 Maps JavaScript API 和 Places API (New)，設定步驟請見 README。

想在哪一帶一次逛完？

在上方搜尋或點選分類，加入幾種想去的地點。我們會把彼此相近的店家分成幾個區域，每個方案列出該區域內的多家同類型地點，方便你挑選。

已套用的篩選

還沒有儲存的方案。在方案卡片或地圖上的彈出卡片按「儲存」，之後就能在這裡隨時打開查看。

加入你想去的特定地點，我們會找出移動距離最短的順序。

    距離為直線估算，僅用於排序。點「路線」可在 Google 地圖取得實際路線。
